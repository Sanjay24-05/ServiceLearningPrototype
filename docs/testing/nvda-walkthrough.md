# NVDA walkthrough (M1 exit)

## Quick pass for sighted testers

Use NVDA's Speech Viewer with the screen on (NVDA menu, Tools, Speech Viewer). Use only the keys H, Tab, Space and Enter. Compare what Speech Viewer shows with the expected transcripts in `tests/transcripts/` (`index.txt`, `report.txt`, `result.txt`). Those transcripts are produced automatically on every test run. They are generated with LibreOffice disabled, so if LibreOffice is installed on your machine, the "LibreOffice was not found" line on the first page and the "skipped" note on the report will not appear; that is not a bug. You only need to confirm three things by ear:

1. The announcements make sense when heard in order.
2. Progress updates are neither spammy nor silent.
3. Applying the fixes and downloading the corrected copy both work.

Every page ends with a "How Slide Proof works" link in the footer; check it reads as a link and opens the explanation page.

## Full walkthrough

To be performed by the developer with NVDA + Firefox and NVDA + Chrome, screen off.

Deck used: `demo_deck.pptx` (generated by `tools/make_demo_deck.py`). Findings are ranked by priority (deterministic), so both slide 4 findings come before the slide 2 one.

Run the whole list once in Firefox and once in Chrome.
