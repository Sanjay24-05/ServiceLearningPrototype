# NVDA walkthrough (M1 exit)

To be performed by the developer with NVDA + Firefox and NVDA + Chrome, screen off.

Deck used: `demo_deck.pptx` (generated by `tools/make_demo_deck.py`). Findings are ranked by priority, so the slide 4 finding heading may come before the slide 2 one; record the order you hear.

Run the whole list once in Firefox and once in Chrome.

| # | Step | Expected | Firefox Pass/Fail | Firefox Notes | Chrome Pass/Fail | Chrome Notes |
|---|------|----------|-------------------|---------------|------------------|--------------|
| 1 | Start `python -m slideproof`; open the page | NVDA reads the page title "Check slide layout – Slide Proof" | | | | |
| 2 | Tab to the file field; choose the demo deck; activate "Check slides" | Hear "PowerPoint file (.pptx)" on the field | | | | |
| 3 | Wait on the progress page | Status updates no more often than every 3 s, then "Report for demo_deck.pptx, heading level 1" | | | | |
| 4 | Press H twice | Hear the slide 2 finding heading and the slide 4 finding heading (either order) | | | | |
| 5 | Press Insert+F7, Headings | Outline matches the report: h1, "Visible problems (2)", two findings, "Apply fixes" | | | | |
| 6 | Tab to each fix checkbox | Label includes "Safe fix." and "checked" | | | | |
| 7 | Activate "Create corrected copy" | Land on "Corrected copy created"; hear "2 fixes applied. 2 problems resolved. 0 new problems." | | | | |
| 8 | Navigate the "Changes made" list; activate the download link | List reads item by item; download starts | | | | |
| 9 | Repeat 1-8 in the other browser | All pass | | | | |

Exit criterion (design section 14, M1): every item passes in both browsers.
