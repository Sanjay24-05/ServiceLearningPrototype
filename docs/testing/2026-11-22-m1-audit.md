# M1 audit: real NVDA pass and realistic decks (2026-11-22)

Environment: Windows 11, LibreOffice 26.8.3, NVDA 2026.3.1, Microsoft Edge, `master` at 1d45cc8.

## 1. Real NVDA pass

**Method.**
- NVDA was started quietly with speech logging (`nvda.exe -m -l 12 -f <log>`).
- `tools/nvda_pass.py` drove Slide Proof in a visible Edge window: page loads, Tab, Enter.
- Everything NVDA said was read back from its log. So this is what NVDA actually spoke, not a simulation.
- NVDA's own quick-navigation keys (such as H) were not pressed; the automated transcript test covers heading order.

## 3. Findings

| # | Severity | Finding | Cause | Proposed fix |
|---|---|---|---|---|
| A1 | Important | Empty file field is announced as "invalid entry" before the user does anything | `required` on the file input | Remove `required`; the server already rejects a missing or wrong file with a clear page |
| A2 | Important | A picture with no text that is up to 50% off the slide is never reported (lecture deck diagram, 37% off) | The spec §7.2 "decorative bleed" exemption is too broad: it was meant for full-bleed backgrounds and banners | Exempt only elements that look like deliberate bleed (spanning ≥ 90% of the slide's width or height, or touching two adjacent edges). Report everything else by the normal C1 rule |
| A3 | Important | Freeform (custom-geometry) shapes are classed as "other" and reported as "could not be checked" | The loader's kind mapping lacks `FREEFORM` | Map freeform shapes to "shape". Only charts, tables, SmartArt and unreadable objects count as "could not be checked" |
| A4 | Minor | Pictures inserted without alt text are named after generic file names, e.g. `picture "image.png"` | The label falls back to the stored file name | Treat generic names (`image.png`, `image12.jpeg`, `Picture 3`) as no name, giving "picture 2" |
| A5 | Minor | On the report page, automatic reading stops after the summary, so the coverage sentence may go unheard | NVDA reads only the focused heading area after a focus move | Move the coverage sentence into the same paragraph as the summary. Ask blind testers whether the order works |
| A6 | Known (spec) | Slide 2 of the old demo was flagged even though no text was cut off | C1 measures the text box outline, not the rendered text | M2/M3: apply the content-box rule to C1 once rendered spans are linked to shapes |
