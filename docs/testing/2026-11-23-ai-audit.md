# AI intent model audit (2026-11-23)

Environment: Windows 11, LibreOffice 26.8.3, NVDA 2026.3.1, Microsoft Edge, scikit-learn 1.5.2. Branch `ai-model`.

## 1. What was built

A small, on-device machine-learning model judges each "sticks out" (C1) and "overlap" (C2) finding: is it a mistake, or a deliberate design?

- **What happens to confident cases:** findings the model is at least 80% sure are deliberate move to a **"Probably intentional"** section, with a spoken reason. They are never hidden: they are listed, counted in the summary, and their fixes stay available, just unticked.
- **Training:** all training data is synthetic. It comes from 120 generated practice decks with labelled deliberate designs and planted mistakes. The full description, numbers and limits are in the model card: `docs/ml/intent-model-card.md`.
- **What is never judged:**
  - text that sticks out past the slide (a title, text box or other text), which always stays in the main list;
  - text overlapping other text.

## 2. Measured results (decks the model never saw, grouped 5-fold)

| | Value |
|---|---|
| Shipped model | Gradient-boosted trees, threshold 0.80 |
| Planted mistakes kept in the main lists | **97.6%** (safety target ≥ 95%: met) |
| Deliberate designs recognised | **94.3%** |
| Precision / F1 | 0.973 / 0.958 |
| Planted mistakes in hand-built test decks moved | 0 |
| Yellow Idea (real template) findings moved | 1 of 5 (not confirmed by a person) |

The threshold and family were chosen on the same out-of-fold predictions that are reported, so these numbers are mildly optimistic. The model is untested on real-world decks.

## 3. Reviews and what they caught

- **The practice-deck generator** had giveaway features: every mistake touched exactly one edge, and nothing large was ever a mistake. Counter-examples were added, and a test now enforces that no single feature separates the classes.
- **The model card** overstated the held-out evidence. It now states the real sizes (tiny) and marks the Yellow Idea move as unverified.
- **The final review found a critical case:** a mistake copied onto several duplicated slides moved to "Probably intentional" at 99–100%. It was fixed three ways:
  - a hard rule that text sticking out is never judged;
  - duplicated-slide mistakes added to the training data, then retrained;
  - re-measured: every such case now stays in the main lists (pictures p ≤ 0.001).
- **Also fixed:**
  - a prediction failure falls back openly instead of breaking the report;
  - spoken certainty is capped at 99%;
  - the "behind" reason is no longer said when it isn't true;
  - the model loads when the app starts.

## 4. Real NVDA pass (deck with a school logo spilling off the same corner of 6 slides)

| Step | NVDA said | Verdict |
|---|---|---|
| Report loads | "Report for school_logo_deck.pptx, heading level 1. 6 slides checked. No visible problems. 0 minor, 6 probably intentional. This version checks seven things: …" | ✅ The moved findings are counted in the summary |
| Tab to a finding's fix | "section, Slide 1: picture 1 sticks out past the left and top edges, region, Fix for this problem, grouping, Move it back onto the slide. Safe fix., check box, **not checked**" | ✅ The fix is offered but unticked |
| Tab | "Layout of slide 1, button, collapsed" | ✅ |

**Observation for user testing:** when tabbing straight to a fix, NVDA announces the finding's heading but not that it sits in the "Probably intentional" section. That is said by the section heading and by the finding's own text ("Probably intentional (99% sure): …"), which a user hears when reading rather than tabbing. Worth asking blind testers whether that's enough.

## 5. Known limits

- An empty rectangle 40% off the left edge on a single slide still moves (p 0.987). It looks like the deliberate side strips in training. It stays listed, with its fix unticked.
- Deliberate banners or footers that contain text are never moved, because text that sticks out is always reported.
- The held-out evidence on real decks is tiny.
- The before/after slide view (design §6 item 3) is not built yet.
