# M2 audit: geometry breadth (2026-11-22)

Environment: Windows 11, LibreOffice 26.8.3, NVDA 2026.3.1, Microsoft Edge. Branch `m2-geometry`.

## 1. What M2 added

New checks:
- **Overlap (C2)** — Measured against the area text actually fills, estimated from inherited formatting.
- **Low-resolution pictures (C5)**
- **Titles out of line (C8)** — Compared only within the same slide layout.
- **Stray fonts (C9)**
- **Empty or stray objects (C10)**

New safe fixes:
- **F3** moves a title in line with the other slides.
- **F4** removes an empty text box.

Report page:
- Each finding gets a "Layout of slide N" disclosure listing every object on the slide in reading order.

## 4. Whole-branch review and fixes

An independent review found two critical false alarms and eight important issues. All are fixed, each with a test that failed first:

1. **Title position (C8)** compared section headers and caption slides with content slides, and its pre-checked fix moved them. It now compares titles within one layout only.
2. **The text estimate** ignored inherited size, alignment and shrink-on-overflow. A logo in the corner of every slide was flagged as covering the centred title, and a real overlap with 32 pt bullets was missed. Formatting is now resolved through slide → layout → master.
3. **A title parked off the slide on purpose** (a common way to give screen readers a title without showing it) is no longer "fixed". It gets a minor note that says it may be intentional.
4. **EMF, WMF and SVG pictures** are no longer called low resolution.
5. **Theme-font references** (`+mn-lt`, `+mj-lt`) are no longer called stray fonts.
6. **Every check has wording** for grouped findings.
7. **Empty titles** are reported as "this slide has no title" and are never deleted. Empty placeholders are named by type ("empty picture placeholder").
8. **Shapes with animations** are never deleted by F4.
9. **A filled caption band** with text inside a photo is no longer an overlap.
10. **The template regression** now covers every installed template.

## 5. Open questions for blind users and the community sessions

- **Half-off-slide decorative graphics.** For example, the Yellow Idea template's half-donut chart runs off the right edge on purpose. The tool reports it as "sticks out". Should graphics like this be exempt?
- **Minor notes about empty placeholders on half-finished decks.** Are these helpful or noisy? Freshes produces 28.
- **Layout-map length on busy slides.** One line per object can get long.
